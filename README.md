# KAWASEMI
  Polar Buzz Shooter

  ハイスピード弾幕系STG「Polar Buzz Shooter」のソース一式です。自機と敵弾がニ極属性（シアン／マゼンタ）を持ち、スレスレ
  回避（BUZZ）によるエネルギー獲得とスコア倍増がゲームの肝になります。最新ビルドでは、敵弾とのニアミス時にプレイヤー機体
  へエフェクトを付与し、危険判定を視覚的に把握しやすくしました。#KGNINJA

  主な特徴

  - ポーラリティ切替: Shiftキーで属性を反転し、吸収・被弾リスクをコントロール。
  - BUZZコンボ: 弾幕ギリギリを掠めるほど倍率が上昇し、一定数でオーバードライブ突入。
  - ビジュアルフィードバック: バズ時は自機周囲に発光リングを描画し、ニアミスを即座に可視化。
  - 軽量実装: 依存ライブラリを持たない純粋なHTML5 Canvas + JavaScript構成。

  クイックスタート

  1. リポジトリをクローン

     git clone https://github.com/your-account/polar-buzz-shooter.git
     cd polar-buzz-shooter
  2. 任意の静的サーバーで polar_buzz_shooter.html を配信

     python3 -m http.server 8080
     # または任意のローカルサーバーを利用
  3. ブラウザで http://localhost:8080/polar_buzz_shooter.html を開いてプレイ

  操作方法

  - 矢印キー / WASD: 移動
  - Shift: ポーラリティトグル（バズ狙いの要）
  - 自動射撃: ショットは自動発射
  - F1: デバッグモード（無敵）切替

  開発メモ

  - コードは polar_buzz_shooter.html 1ファイル構成。Canvas描画ループとゲームロジックを内包。
  - 日本語コメントを各所に記載し、処理意図を明文化。
  - バズ演出は player.buzzEffectTimer で持続時間を管理、描画は drawPlayer() 内で行う。
  - 音声はブラウザ依存（AudioContext）。ローカル環境でサウンドが鳴らない場合はHTTPSまたはユーザー操作後に初期化してくだ
    さい。

  テスト

  - ブラウザでBUZZ発生時に自機発光が再生されるかの手動確認を推奨。
  - ローカルで負荷テストを行う場合は、ウィンドウ解像度やDPRを変更してフレームレートを検証。
